Proyecto Principal: Plataforma Web PWA «Estado del Mar»

Contexto: Proyecto Integrador Intermodular (PIM · 2º DAW · IES María Enríquez) · Rol: Lead Full-Stack Developer & UI/UX Designer
Repositorio: github.com/gscristian95/Project2DAW_CristianGomez (ramas: main, Sprint0, Sprint1)
Stack: PHP 8.x (PDO/POO), MySQL 8.0 (InnoDB), JavaScript Vanilla (ES6 Modules), Service Workers, IndexedDB, Tailwind CSS, REST APIs (AEMET, Puertos del Estado), Copilot IA.

Hitos técnicos principales

  1. Caché en servidor y optimización de cuotas API: Tabla de persistencia telemetria_cache en MySQL 8.0 para respetar el límite de AEMET (<10 req/min). Un proceso programado sincroniza cada 10-15 minutos y el cliente consulta solo endpoints locales, con respuestas inferiores a 3 segundos.
  2. Modelo relacional normalizado de 7 entidades: Claves foráneas con ON DELETE CASCADE, coordenadas GPS en DECIMAL(9,6) (WGS84) e índices compuestos con clave de unicidad para evitar duplicados.
  3. Resiliencia offline en PWA: Service Workers e IndexedDB guardan en el dispositivo los últimos 15-30 minutos de lecturas y cartografía vectorial, para consultar condiciones marítimas sin cobertura móvil.
