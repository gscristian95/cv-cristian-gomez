Proyectos

Plataforma Web PWA «Estado del Mar» (PIM)

Proyecto Integrador Intermodular de 2º DAW como Lead Full-Stack Developer y UI/UX Designer. Stack: PHP 8.x (PDO/POO), MySQL 8.0, JavaScript ES6, Service Workers, IndexedDB, Tailwind CSS y APIs REST (AEMET, Puertos del Estado).

Hitos técnicos

  • Hito 1: Caché en servidor y cuotas de API
    • Tabla telemetria_cache en MySQL 8.0, sincronizada cada 10-15 minutos.
    • Cumplimiento de la cuota de AEMET (<10 req/min) con respuestas inferiores a 3 segundos.
  • Hito 2: Modelo relacional normalizado de 7 entidades
    • Claves foráneas con ON DELETE CASCADE y coordenadas GPS en DECIMAL(9,6).
    • Índices compuestos y clave de unicidad para evitar duplicados en la telemetría.
  • Hito 3: Resiliencia offline (PWA)
    • Service Workers e IndexedDB para guardar entre 15 y 30 minutos de lecturas y cartografía.
    • Consulta de condiciones marítimas en la costa aunque no haya cobertura móvil.
  • Hito 4: Diseño táctil «Zero Social Noise»
    • Paleta WCAG AA para visibilidad bajo sol directo y áreas táctiles de 48px o más.
    • Chips de telemetría comunitaria de un solo toque. Auditoría de Nielsen con 10/10 PASS.
  • Hito 5: Ciclo de vida ágil y desarrollo asistido
    • Scrum en 3 Sprints con Git Flow formal.
    • Integración de un agente de IA mediante .github/copilot-instructions.md.
